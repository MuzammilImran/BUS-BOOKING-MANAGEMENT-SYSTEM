# Bus Booking Management System

A web-based Bus Booking Management System developed using ASP.NET Web Forms, C#, and SQL Server.  
The application allows users to search for buses, select seats, enter passenger information, and manage bookings.

## Features

- User registration and login
- Search available buses
- View bus schedules and details
- Select available seats
- Enter passenger information
- Generate booking reports
- Admin panel for managing bus records
- SQL Server database integration

## Technologies Used

- ASP.NET Web Forms
- C#
- .NET Framework
- SQL Server
- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery
- Visual Studio
